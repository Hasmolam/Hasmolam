## Hakkımda · About

**TR** — Müşteriler için canlıya çıkan web uygulamaları geliştiren bir full-stack geliştiriciyim. Laravel + Filament ile yönetim panelleri, Next.js + Sanity ile içerik odaklı siteler kuruyorum; kişisel projelerimde Python (FastAPI) ve React Native kullanıyorum. **EN** — Full-stack developer shipping production web applications for real clients.
